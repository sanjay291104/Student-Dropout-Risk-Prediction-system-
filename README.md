# Pulse.edu — Student Dropout Risk Prediction & Intervention Recommendation System

Flask + Machine Learning web app that predicts student dropout risk and
recommends interventions, built for the TKREC CSE major project.

## Project Structure

```
dropout_system/
├── app.py                       # Flask application (routes, auth, prediction logic)
├── train_model.py                # Trains all 9 ML models on the dataset
├── student_dropout_dataset.csv   # Training data (10,000 records)
├── requirements.txt
├── models/                       # Generated by train_model.py
│   ├── best_model.pkl             # Best proposed model (pickled)
│   ├── scaler.pkl                 # StandardScaler
│   ├── encoders.pkl               # LabelEncoders per categorical column
│   ├── feature_columns.pkl        # Ordered feature list
│   ├── metrics.json                # Accuracy/Precision/Recall/F1 for all 9 models
│   └── feature_importance.json     # Feature importance of the best model
├── templates/
│   ├── base.html                  # Shared navbar/footer
│   ├── landing.html
│   ├── login.html
│   ├── register.html
│   ├── dashboard.html
│   ├── history.html
│   └── about.html
└── static/
    ├── css/style.css              # Full design system (14-hue accent palette)
    └── js/script.js               # Shared JS (nav, reveal-on-scroll, counters)
```

## Models

**Existing System (baseline)**: Logistic Regression, Decision Tree, KNN,
Naive Bayes, SVM, ANN (MLPClassifier)

**Proposed System**: Decision Tree, Random Forest, XGBoost — the
best-performing one (by F1-score) is automatically selected and saved as
the production model used by the Flask app.

## Setup

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Train all models (creates the models/ folder artifacts)
python train_model.py

# 3. Run the Flask app
python app.py
```

Then open **http://localhost:5000** in your browser.

## Retraining

If you replace `student_dropout_dataset.csv` with a new dataset (same
column schema), just re-run `python train_model.py` — it regenerates every
artifact in `models/`, and the Flask app will automatically pick up the new
model, metrics, and feature importances on next launch.

## Notes

- Passwords are hashed with Werkzeug's `generate_password_hash`.
- SQLite (`database.db`) stores users and prediction history; it is created
  automatically on first run.
- Intervention recommendations are produced by transparent rule-based logic
  in `app.py::generate_recommendations`, layered on top of the ML
  probability score — this is what makes the system explainable rather
  than a black box.
